Painel DevOps (atalho na Área de Trabalho e no painel)
--------------------------------------------------------
 Um painel visual único para Docker, Jenkins, Git, VS Code,
 Terraform, Python e Monitoramento. Tudo com botões e modelos prontos:
   - criar containers (site, MySQL, PostgreSQL, Redis...),
     projetos Docker Compose e imagens com Dockerfile;
   - criar, editar e rodar pipelines do Jenkins, vendo as
     etapas e a saída ao vivo;
   - commit, branches, push, pull e clone no Git;
   - init/plan/apply/destroy do Terraform;
   - ligar Grafana, Prometheus e Uptime Kuma com um clique;
   - projetos Python com .venv e pacotes;
   - gráficos de memória, processador, builds e commits.
 Endereço: http://localhost:8090 (favorito "Painel DevOps" no Firefox;
 só abre dentro da VM)

Comandos rápidos
----------------
 code .                         abre a pasta atual no VS Code
 docker run hello-world         testa o Docker (sem sudo)
 docker compose up              sobe um compose.yaml
 terraform init                 inicia um projeto Terraform
 python3 -m venv .venv          cria um ambiente Python
 sudo apt install NOME          instala outro programa

Dicas
-----
 - Use a pasta ~/projetos (atalho "projetos" aqui ao lado).
 - Para levar seu trabalho: git push para o seu GitHub.
 - Copiar/colar e arrastar arquivos entre o Windows e a VM
   já estão ligados.
 - Maximize a janela do VirtualBox: a resolução se ajusta.
 - Se a VM estiver lenta, aumente a memória para 6 GB em
   Configurações > Sistema no VirtualBox (com ela desligada).
