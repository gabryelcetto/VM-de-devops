Ferramentas instaladas
----------------------
 - Ubuntu 24.04 LTS com XFCE
 - VS Code ............ menu Aplicativos > Desenvolvimento, ou: code
 - Docker ............. docker run hello-world
 - Docker Compose ..... docker compose version
 - Git ................ git --version
 - Ansible ............ ansible --version
 - Terraform .......... terraform -version
 - Python 3 ........... python3 --version  (pip3, venv, pipx)
 - Jenkins LTS ........ http://localhost:8080

Para conferir tudo de uma vez, abra o Terminal e rode:

    verificar-lab

Jenkins - primeiro acesso
-------------------------
1. Abra o Firefox em http://localhost:8080
2. Cole a senha inicial do administrador:

       __JENKINS_PASSWORD__

   (ela também fica em /var/lib/jenkins/secrets/initialAdminPassword)
3. Escolha "Install suggested plugins" e crie seu usuário admin.

O usuário "jenkins" já está no grupo docker, então pipelines
podem rodar comandos docker.

Dicas
-----
 - Use a pasta ~/projetos para seus trabalhos.
 - Área de transferência e arrastar/soltar entre host e VM
   já estão ativados.
 - Se a VM estiver lenta, aumente a memória para 6-8 GB em
   Configurações > Sistema no VirtualBox.
