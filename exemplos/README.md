# Exemplos para o Jenkins

`Jenkinsfile` é o pipeline usado pelos modelos **Pipeline do Git** e **Multibranch** do Painel DevOps.
Ele baixa este repositório, mostra o último commit, faz um teste simples e roda um container.

Para o seu trabalho: crie um arquivo `Jenkinsfile` na raiz do **seu** repositório no GitHub e,
no Painel, troque o endereço do repositório e o caminho do Jenkinsfile.
