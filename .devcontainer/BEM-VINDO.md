# Bem-vindo ao DevOps-Lab-UVV (no navegador)

Tudo já está instalado: **VS Code** (este editor), **Docker + Docker Compose**, **Git**,
**Ansible**, **Terraform**, **Python** e **Jenkins**.

## Primeiros passos

1. Abra o terminal: menu ☰ → **Terminal → Novo Terminal**.
2. Confira o ambiente:
   ```bash
   verificar-lab
   ```
3. **Jenkins:** aba **PORTAS** (ao lado do Terminal) → porta **8080** → ícone do 🌐.
   Senha inicial:
   ```bash
   cat ~/JENKINS-SENHA-INICIAL.txt
   ```
4. **Área de trabalho gráfica (opcional):** aba **PORTAS** → porta **6080** → 🌐 →
   clique em **Connect** e use a senha **devops**.

## Dicas

- Seus arquivos ficam salvos neste Codespace (separado dos outros alunos).
- Use a pasta `~/projetos` ou este próprio repositório para seus trabalhos.
- Ao terminar a aula, o Codespace desliga sozinho depois de 30 min parado.
  Para voltar: https://github.com/codespaces
